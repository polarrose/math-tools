# Calculus Interactive Tools

**Live page:** https://polarrose.github.io/math-tools/calculus/

Interactive practice activities for Calculus I and Calculus II, by Polar Rose Studio. Each activity is one self-contained web page that works on a phone or a computer, with nothing to install and no sign-in.

## Activities

### Calculus I

## How the activities work

- Problems are numbered across the top. Each problem is a short series of multiple-choice steps, each with its own Check button.
- A wrong answer turns violet and says "Not quite. Try again." The correct answer is never revealed; students keep trying.
- An explanation is available after each check.
- A problem earns a check mark when every step is right on the first try. "Try this problem again" lets students redo a problem and turn an X into a check mark.
- No scores, no timers, no sign-in, and nothing is saved.

## Accessibility and privacy

- Works with a keyboard alone and with screen readers (NVDA, VoiceOver). Math is read aloud through MathJax's built-in speech text.
- Text and controls meet WCAG AA contrast in light and dark mode. Pinch-zoom works, and reduced-motion settings are respected.
- No cookies, no tracking, no data collected. System fonts only (no Google Fonts). Each page has a strict Content-Security-Policy.
- Every activity is audited for accessibility, security and mathematical accuracy before it is published.
