The Convergence Tests

nth term test. If \(\displaystyle\lim_{n\to\infty} a_{n} \neq 0\), the series \(\displaystyle\sum_{n=1}^{\infty} a_{n}\) diverges. If \(\displaystyle\lim_{n\to\infty} a_{n} = 0\), the test is inconclusive.

Geometric series test. A geometric series \(\displaystyle\sum_{n=1}^{\infty} a\,r^{n-1}\) with common ratio \(r\) converges when \(\left|r\right| < 1\), and its sum is \(\dfrac{\text{first term}}{1-r}\). It diverges when \(\left|r\right| \ge 1\).

p-series test. \(\displaystyle\sum_{n=1}^{\infty}\frac{1}{n^{p}}\) converges when \(p > 1\) and diverges when \(p \le 1\).

Integral test. If \(f\) is positive, continuous and decreasing for \(x \ge 1\) and \(a_{n} = f(n)\), then \(\displaystyle\sum_{n=1}^{\infty} a_{n}\) and \(\displaystyle\int_{1}^{\infty} f(x)\,dx\) both converge or both diverge.

Limit comparison test. If \(a_{n} > 0\), \(b_{n} > 0\) and \(\displaystyle L = \lim_{n\to\infty}\frac{a_{n}}{b_{n}}\) is finite and positive, then \(\displaystyle\sum_{n=1}^{\infty} a_{n}\) and \(\displaystyle\sum_{n=1}^{\infty} b_{n}\) both converge or both diverge.

Alternating series test. \(\displaystyle\sum_{n=1}^{\infty} (-1)^{n+1} a_{n}\) with \(a_{n} > 0\) converges if \(\displaystyle\lim_{n\to\infty} a_{n} = 0\) and the terms \(a_{n}\) are decreasing (from some point on).

[Note: If \(a_{n} > 0\) and \(\displaystyle\lim_{n\to\infty}a_{n} = 0\), then we can assume \(a_{n}\) is decreasing (from some point on), as long as \(a_{n}\) has no oscillating parts such as \(\sin n\) or \(\cos n\).]

Ratio test. Let \(\displaystyle L = \lim_{n\to\infty}\left|\frac{a_{n+1}}{a_{n}}\right|\) for the series \(\displaystyle\sum_{n=1}^{\infty} a_{n}\). If \(L < 1\), the series converges. If \(L > 1\) (or \(L = \infty\)), the series diverges. If \(L = 1\), the test is inconclusive.
