# Math Tools

This repository contains twelve browser-based practice games for intermediate algebra, from arithmetic
review through functions. No download is needed; no need to create an account. Students can use a phone or a computer and just play the games to develop proficiency in the topics listed below.

Additional games and a separate suite of calculus visualizations/games is being planned for the next few months.

To see all the games, just visit:

**Live site:** https://polarrose.github.io/math-tools/

---

## The games

| Game | Content |
|---|---|
| [Arithmetic Fluency](arithmetic-fluency/) | Addition, subtraction, multiplication, mixed drill |
| [Signed Numbers](signed-numbers/) | Operations with positive and negative numbers |
| [Solving Linear Equations](solving-linear-equations/) | One- and multi-step equations, with a fully guided level |
| [Linear Applications](linear-applications/) | Word problems: rates, break-even, modelling from two points |
| [Finding the Slope](finding-the-slope/) | Slope from points, graphs, and equations |
| [Graphing Linear Equations](graphing-linear-equations/) | Plotting points and lines on a coordinate grid |
| [Exponent Rules](exponent-rules/) | Product, quotient, power, zero, negative and fractional exponents |
| [Radical Expressions](radical-expressions/) | Simplifying, multiplying, and rationalizing radicals |
| [Complex Numbers](complex-numbers/) | Simplifying, arithmetic, and division with i |
| [Systems of Equations](systems-of-equations/) | Substitution, elimination, and applications |
| [Solving Linear and Quadratic Equations](quadratic-equations/) | Factoring, the quadratic formula, and mixed practice |
| [Domain, Range & Functions](domain-range-functions/) | Interval notation, reading graphs, evaluating f(x), the vertical line test |

Each game keeps progress on the student's own device, tracks accuracy per topic,
and points them toward whichever category they are weakest in.

## For students

Open the link. Pick a topic. Start answering. Nothing to install, nothing to
sign up for, and your progress is saved on your own phone or laptop — not on a
server, and not visible to anyone else.

## For instructors 

Paste the site link into a Canvas announcement, email or module page. Every game is a single  self-contained HTML file, so there is nothing to configure.  Once a student clicks on the link, they will be able to start playing the game. If it is preferred to provide a link to a single topic, you can do so easily by copying the URL for that specific game and just sharing that with the students.

## Accessibility

Every game was built and tested against WCAG 2.1 AA. Specifically:

- The page zooms. Pinch-zoom is never blocked.
- Every problem is announced in words, not read as raw symbols, so a radical or
  a stacked fraction is spoken as "the square root of 72" rather than as markup.
- Every game is fully playable with a keyboard alone, including the graphing
  game, where points can be plotted with the arrow keys.
- Every input has a real label, every mode button reports whether it is selected,
  and every answer produces a spoken response.
- Color is never the only signal. Animation respects `prefers-reduced-motion`.
- Text contrast meets AA throughout, including in states that only appear after
  you interact — revealed answers, stats panels, disabled fields.

The bar was not "readable." It was playable: a student who cannot see the
screen can start a game, choose a mode, answer five problems, and know how they
did.
